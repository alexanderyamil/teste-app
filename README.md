# Calculadora da Media Escolar
## Descripção: 
um mini programa onde pode calcular a media de um estudante com aprovação e reprovação
## Tecnologias Utilizadas
* utilizado a ferramenta programa visual studio code**
* utilizado a ferramenta python
## Como instalar e executar:
- verificar se tiver a versão de python v2026.4.0
- fazer um codigo simples no liguagem pythom utilizando a media ('app.py')
- executar o arquivo na terminal 
## Exemplo de uso e demostração:
- a nota de um aluno x consegue na primera nota 7 e na segunda nota ele tira 8 dentro do programa faz um analise rapido e na saida mostra a media de 7.50 E seu status APROVADOA
